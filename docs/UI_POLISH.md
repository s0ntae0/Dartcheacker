# UI 다듬기 지시서 (docs/UI_POLISH.md)

목표: 파이프라인·응답 계약은 그대로 두고, `app/page.tsx`(+ `app/layout.tsx`, `app/globals.css`)만 손봐서 "실서비스" 인상을 만든다. 기능 추가는 §7의 2개뿐. 작업 예산 3~4시간. 순서대로 진행하고 각 단계마다 375px·1280px 두 폭에서 확인.

## 1. 아이덴티티

- 폰트: Pretendard (`<link>` jsdelivr CDN, `font-family: Pretendard, -apple-system, ...`). 숫자는 `font-variant-numeric: tabular-nums`.
- 컬러 토큰 (Tailwind config 또는 CSS 변수):
  - `--brand: #1E3A8A` (딥 네이비, 금융 신뢰) / `--brand-ink: #0F172A` 텍스트
  - `--accent: #2563EB` 버튼·링크
  - 등급: low `#16A34A`, medium `#D97706`, high `#DC2626`, uncertain `#64748B`
  - 배경: 페이지 `#F8FAFC`, 카드 `#FFFFFF`, 카드 테두리 `#E2E8F0`
- 로고: 텍스트 로고 "찌라시체크" 앞에 SVG 마크 하나 (24px, 체크 표시가 든 말풍선 — 인라인 SVG로 직접 그림, 외부 이미지 금지). favicon도 같은 마크.
- `layout.tsx` metadata: title "찌라시체크 — 리딩방·SNS 주식 메시지 공시 검증", description, `openGraph`(title·description·siteName), `themeColor: #1E3A8A`, viewport.

## 2. 레이아웃

- 상단 헤더(sticky, 흰 배경, 하단 1px 테두리): 좌측 로고, 우측 앵커 링크 3개 "작동 원리" "신고처" "출처". 모바일에선 링크 숨기고 로고만.
- 본문 최대폭 640px 중앙. 섹션 간격 24px.
- 푸터: 출처(금융감독원 소비자경보 · 금융위원회 · OpenDART · 자본시장법) 한 줄, 면책 문구, "데이터 기준: 최근 90일 공시 · 상장사 3,989개사", GitHub 링크 없음(코드 공개 안 함).

## 3. 첫 화면 (검사 전) — 지금 제일 약한 부분

위에서 아래로:

1. **히어로** (배경 `--brand` 그라데이션 아주 옅게 또는 흰색, 텍스트 좌정렬)
   - H1: "그 메시지, 공시로 확인하세요"
   - 서브: "리딩방·오픈채팅·SNS에서 받은 주식 메시지를 붙여넣으면 사기 수법 일치 여부와 공시 근거를 30초 안에 알려드립니다."
   - 신뢰 배지 3개(작은 pill, 아이콘 없이 텍스트): "금융감독원 소비자경보 기준" · "OpenDART 실시간 대조" · "판정 근거 전부 인용"

2. **입력 카드** (현재 것 유지하되)
   - textarea 높이 160px, 포커스 시 테두리 `--accent`.
   - 버튼 문구 "검사하기" → **"공시로 확인하기"**. 높이 52px, 둥근 12px, `--accent`. 로딩 중엔 버튼 안에 단계 텍스트가 바뀜: "사기 수법 대조 중…" → (1.5초 후) "공시 조회 중…" (실제 단계와 무관하게 타이머로, 응답 오면 종료).
   - 글자 수 카운터는 우측 하단 회색 유지.

3. **예시 카드 섹션** — 버튼 3개를 이걸로 교체
   - 섹션 제목: "이런 메시지, 받아보셨나요?"
   - 카드 3장(모바일 세로, 데스크톱 가로 3열). 각 카드: 상단 작은 라벨(회색) "리딩방 메시지" / "종목 커뮤니티 글" / "오픈채팅 공지", 본문은 예시 텍스트 앞 2줄(line-clamp-2), 하단 "이 메시지로 검사 →" 링크 스타일.
   - 클릭 시 textarea에 채우고 **자동으로 검사 실행** + 결과로 스크롤.
   - 섹션 하단 회색 한 줄: "예시는 실제 사실이 아닌 가상 메시지입니다. 기업명은 검증 시연을 위해 실제 상장사를 사용했습니다."
   - `data/examples.ts`의 `[예시 — …]` 접두사는 제거하고 위 고지문으로 대체(서버 strip 로직도 제거).

4. **작동 원리** (앵커 `#how`) — 3단 가로 스텝, 아이콘 대신 숫자 원
   - ① 붙여넣기 — "메시지를 그대로 넣습니다. 회원가입 없음"
   - ② 두 가지 대조 — "금감원이 유형화한 사기 수법 16종과 표현을 대조하고, 메시지 속 주장을 DART 공시와 비교합니다"
   - ③ 근거와 함께 판정 — "매치된 구절, 법 조문, 공시 원문 링크를 함께 보여줍니다. 미확인은 미확인으로만 표시합니다"

5. **오늘의 검사** (§7-1 기능) — 작은 통계 스트립: "오늘 N건 검사 · 높음 M건 · 누적 T건". `/api/stats` 신설(GET, checks 집계, 60초 캐시). 0건이면 스트립 숨김.

6. **신고처** (앵커 `#report`) — patterns.json `action_guide.contacts`를 카드 그리드로. 전화는 `tel:`.

## 4. 결과 화면

검사 후엔 히어로·작동 원리·예시 섹션을 **접는다**(히어로는 H1만 작게 남김). 결과가 첫 화면이 되도록.

### 카드 A — 위험 신호 지수
- 상단: 카드 제목 좌측, 우측에 "결과 복사" 버튼(§7-2).
- 지수 표시: 큰 숫자 대신 **반원 게이지**(SVG, 0~100, 등급 색으로 채움) + 중앙 숫자 + 하단 등급 배지. 게이지 폭 160px.
- headline은 게이지 우측(데스크톱) / 아래(모바일).
- hard 배너: 게이지 위에 빨간 배경 전체폭, 아이콘 없이 굵은 텍스트 "금융감독원이 '100% 사기'로 안내한 신호가 포함돼 있습니다".
- 진행 단계 바: 현재 유지. 단 라벨 "사기 진행 단계(추정)" → "이 메시지가 해당하는 단계".
- "정상일 가능성 검토" 박스: 유지하되 제목을 "반대로 생각해보면" 으로. 회색 배경.
- 패턴 카드: 현재 구조 유지. 인용 구절은 등급 색 좌측 보더 + 이탤릭 없이. "법적 근거 보기" 토글 텍스트 링크. 출처는 도메인만 표시(예: "fsc.go.kr").
- "다음에 올 가능성이 높은 것" 박스: 노란 배경, 제목 "이 다음에 올 수 있는 것".
- 정상 신호 배지: 초록 pill, 카드 A 하단.

### 원문 하이라이트
- 카드 제목 "원문에서 걸린 부분". mark 배경은 등급색 15% 투명도, 글자색 진하게.

### 카드 B — 공시 대조
- 제목 "메시지 속 주장, 공시로 확인". claim 0건이면 카드 자체를 숨기지 말고 "기업명이 포함된 구체적 주장이 없어 공시 대조를 하지 않았습니다" 한 줄.
- 각 claim: 좌측 verdict 배지(색·문구 현재 유지), 우측 주장 텍스트(따옴표) + detail + note(회색 작게) + DART 링크 버튼("공시 원문 보기 ↗", 새 탭).

### 행동 요령
- 제목 등급별: high "지금 하지 말아야 할 것" / medium "확인할 것" / low "참고". 체크리스트 스타일(원형 불릿).

### 하단
- "최종 확인 2026-09-06 14:32 KST" + degraded 배너 + 면책. 그 아래 "다른 메시지 검사하기" 버튼(위로 스크롤 + textarea 비움).

## 6. 접근성·반응형

- 버튼·링크 터치 영역 44px 이상. 색만으로 등급 구분하지 않음(배지 텍스트 병행).
- 375px에서 가로 스크롤 0. 게이지·스텝은 세로 스택.
- `prefers-reduced-motion`이면 게이지 애니메이션 끔.

## 7. 추가 기능 (딱 2개, 둘 다 features.md에 행 추가)

### 7-1. 오늘의 검사 통계
- `GET /api/stats` → `{ today: {total, high}, all: {total} }`. Supabase `checks`에서 `created_at >= KST 오늘 0시` count, `risk_level='high'` count, 전체 count. 응답 `Cache-Control: s-maxage=60`.
- 첫 화면 히어로 아래 스트립. features.md 28번: "검사 통계 — 오늘/누적 검사 건수, 높음 등급 건수 표시(60초 캐시)".

### 7-2. 결과 공유(복사)
- 카드 A 우상단 "결과 복사". `navigator.clipboard.writeText`로 아래 형식:
  ```
  [찌라시체크 결과] 위험 신호 지수 92 · 높음
  일치 유형: 미공개·내부 정보 주장 / 긴급·희소성 압박 / 외부 채널 이동
  공시 대조: 에코프로 미국 수주 — 공시 근거 미확인 (2026-09-06 14:32 KST 기준)
  자세히: https://dartcheacker.vercel.app
  ```
- features.md 29번: "결과 공유 — 판정 요약 텍스트 복사(채팅방 재공유용)". 실패 시(클립보드 권한 없음) 텍스트 영역을 모달로 띄워 수동 복사.
