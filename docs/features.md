# 기능 명세 (기능명세서 §2용)

배포 URL: https://dartcheacker.vercel.app/ · 단일 페이지(좌 사이드바 + 우 메인, ≤900px 드로어) · 서버는 Next.js Route Handler 3개(check/health/stats)

## 판정 표현 원칙

- 판정 대상은 메시지의 **표현**이며 발신자가 아니다. 업체명·인명을 판정문에 자동 삽입하지 않는다.
- "사기입니다 / 사기꾼 / 허위 / 가짜 / 불법 업체 / 사기 확률 N%" 표현을 쓰지 않는다. 허용 프레임: "금감원 소비자경보·금융위 보도자료에서 안내한 유형과 일치 / ~위반 소지가 있는 유형 / ~에 해당할 수 있음".
- 공시 미확인은 "공시 근거 미확인"으로만 표시하고 확인 시각과 공시 의무 기한을 함께 안내한다.
